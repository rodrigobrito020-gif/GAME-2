# GAME-2

Este é um jogo novo de fazenda, independente do GAME-1. Leia DESIGN.md antes de alterar o escopo.

- Não copie nem altere os arquivos do GAME-1 para desenvolver este projeto.
- Use arte própria; referências visuais não autorizam afirmar que os recursos do jogo original estão disponíveis.
- Teste o ciclo de plantio, crescimento, colheita, venda e persistência antes de entregar mudanças.
- Confira visualmente a interface na plataforma escolhida.
- As entradas `index.html` e `public/index.html` são HTMLs autocontidos gerados por `npm run build`, assim como `dist/JOGAR.html`. Edite `src/index.template.html` e os arquivos CSS/JS em `public/`, depois gere novamente. Teste também a prévia em iframe isolado sem recursos auxiliares.
- Relate apenas os testes executados e diferencie uma versão local de uma publicação no GitHub ou na web.
